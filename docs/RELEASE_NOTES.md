觅文 SeekWords v1.1 改进了大范围扫描时的结果查看与操作。

- 已检查、命中和错误计数直接显示连续数字，例如 `668888`。
- 结果可按完整命中关键词与命中来源筛选，继续支持路径搜索、类型、类别和后缀筛选；`Ctrl+F` / `⌘F` 可快速聚焦搜索框。
- 折叠按钮移入侧边栏，收起后保留窄栏中的展开按钮；结果与匹配预览之间使用更清晰的拖动条。
- 导出报告时可以勾选“报告仅含当前筛选”；HTML、TXT、JSON 报告会注明导出范围。
- 调整结果统计区高度，避免数字被截断。

提供 Windows x64、Linux x64、macOS Intel 与 Apple Silicon 的独立包，以及对应标签的完整源码。安装包未签名或 Apple 公证。内容扫描仍以可访问、已选择且可解析的文件为限；读取失败与跳过项在扫描覆盖及错误记录中查看。
