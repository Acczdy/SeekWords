觅文 SeekWords v1.0 是新的公开发布版。

- 首次启动词表为空，可自行添加、删除和导入关键词。
- 统一了文件操作确认和右键菜单样式；批量删除优先使用系统回收站，失败项保留在结果中供核对。
- 新增离线 HTML 报告：扫描概览、按类型及文字筛选、命中位置和高亮片段；同时支持 CSV、TXT、JSON。
- 提供新版图标、Windows x64、Linux x64、macOS Intel / Apple Silicon 安装包及完整源码。
- 继续支持文件名与文档内容扫描、全盘范围设置、动态进度和覆盖统计。

请在下载前核对操作系统与架构。安装包未签名或公证；首次运行时系统可能显示来源提醒。内容扫描只覆盖已选且可解析的格式，权限、占用、加密和图片文档等跳过项会进入错误与覆盖统计。
