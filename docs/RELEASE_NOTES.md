# 觅文 SeekWords v1.2

本版增加可选择的配置、应用缓存、回收站和 Windows 注册表扫描，帮助在普通目录之外查找关键词。首次启动仍无内置关键词；扫描不会自动开始。

- 新增常见 Office/WPS、微信/钉钉、浏览器、系统配置和缓存位置发现，支持可读取的文本、plist 与 SQLite 数据库。Windows 只读遍历 HKCU、HKLM、HKU 的键名、值名、文字和数字值；二进制及权限受限项记入覆盖/错误统计。
- 新增 Windows、macOS、Linux 的回收站位置。Windows `$I` 元数据及 Linux XDG `.trashinfo` 可读取时展示原路径与删除时间。回收站结果在本工具中仅供查看。
- 可选图片 OCR，默认关闭。Windows、Linux、macOS 安装包内置 RapidOCR/ONNX 的中英文模型，支持 PNG/JPEG/TIFF/BMP，显示命中文字及像素位置；无需另装 OCR 程序。源码运行可按 `requirements-ocr.txt` 安装依赖。
- 结果增加“位置来源”列与组合筛选；文件管理器可定位结果，常见文档/图片双击可用默认程序打开。导出报告按来源筛选，并说明额外范围和覆盖情况。
- 扫描结束保存命中目录；“上次命中目录”可填入仍存在的位置，供下一次手动复查。保存记录最多 500 个目录，不包含回收站结果。

提供 Windows x64、Linux x64、macOS Intel 与 Apple Silicon 的独立包，以及对应标签源码。发布包未签名或 Apple 公证。OCR 仅在本机运行，内置模型缺失或校验失败时不会联网下载。系统痕迹仅限可读文件与注册表文字，不含 USN、事件日志、Prefetch、SRUM 等二进制记录解析，也不提供后台实时监控。读取失败、超限和跳过项请结合扫描覆盖与错误清单核对。
