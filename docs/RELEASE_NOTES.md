# 觅文 SeekWords v1.3

本版改进检索结果的筛选与批量操作，支持删除注册表结果。

- 结果区新增“排除词”，任一词命中路径、详情或匹配摘要时隐藏结果；支持逗号、分号、换行分隔，可与原有筛选组合，清空即可恢复。选择“报告仅含当前筛选”时，导出同样排除这些结果。
- 修复删除或移动后跳回第一行的问题，保留当前视图位置，删除选中行后选中相邻结果。
- Windows 注册表结果支持删除指定值或整个键及其子项。确认框列明范围；父子项自动合并，权限失败保留在列表中。扫描不会修改注册表。
- 结果左侧增加连续行号，随筛选、排序和删除更新。
- 修复列宽拖动后回弹，增加列宽保存和恢复。

Windows 注册表删除只在用户确认后执行；删除键会包含其全部子键和值，不进入系统回收站。权限不足会报告失败。

提供 Windows x64、Linux x64、macOS Intel、macOS Apple Silicon 安装包及对应源码。保留离线中英文 OCR、文档内容检索和原有扫描功能。
